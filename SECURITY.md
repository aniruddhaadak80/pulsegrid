# Security Policy

PulseGrid serves only public, keyless feeds (USGS, NOAA SWPC, NASA EONET) and computes a deterministic index. No secrets, no auth tokens, no PII.

- Report vulnerabilities via GitHub Issues (or email the maintainer). Please do not open a public exploit PoC.
- We aim to acknowledge within 72 hours.
- Supported: the latest `main` release only.
